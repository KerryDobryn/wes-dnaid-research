# 隐私与发布边界

公开 ID 一般不能让别人直接读取基因型，前提是随机密钥安全且实现正确。但相同 ID 可关联不同记录，一旦与真实姓名公开，它就是可追踪的身份标签。知道某人 ID 不证明持有其 DNA。不要将 ID 用作口令、访问令牌或单独的本人认证凭据。

同一基因型在不同密钥或命名空间下可生成不同标识。命名空间更换只能减少简单字符串关联，不能防止设备、账户、姓名等其他渠道的关联。

密钥以 32 字节文件保存，在支持 POSIX 权限的平台请求 0600；它**没有加密**，Windows 权限表现可能不同。磁盘加密、系统备份和云同步需自行检查。不要公开密钥、规范基因型、无密钥的内部 SHA 摘要、个人位点集合、VCF、BAM、FASTQ、截图或含本地路径的日志。

实际面板是按初次样本质量选择的，虽然没有写入基因型，也可能暴露样本选择/覆盖信息。因此公开包只提供合成面板，个人面板保留私有。三位点示例没有隐私或识别强度保证。

`.gitignore` 只是辅助，不能撤销已经提交的秘密。示例 VCF 是显式允许的合成文件，不要把真实 VCF 放进 examples。首次发布前运行 `git diff --cached` 并核查提交文件。若密钥进入 Git 历史，应视为泄露；换密钥将改变现有 ID。

基因型不是可随意更换的密码。密钥泄露后，攻击者若掌握候选基因型可进行验证；亲属、同卵双胞胎及群体频率也影响生物学区分能力。未经群体与独立重测验证，本项目不提供唯一性概率。
